# The Federal — YouTube Trends

Editorial intelligence dashboard for discovering rising YouTube topics and content opportunities.

## Stack

- Next.js App Router
- React + TypeScript
- Vercel Fluid Compute

## Current MVP

- Trending topics dashboard
- Region and category filters
- Search
- Trend velocity visualization
- Rising keyword signals
- Editorial opportunity cards

The current dashboard uses prototype data. The next step is connecting a YouTube data source and persistent historical trend snapshots.
